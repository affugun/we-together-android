# WE TOGETHER - Native Android Messaging App
Package: com.wetogether.app
Theme: WhatsApp Green (#075E54 / #128C7E / #25D366)

## How to Build the APK (Complete Beginner Guide)

### Option 1: Using Android Studio (Recommended, takes 3 minutes)
1. Download and install Android Studio (Free from developer.android.com).
2. Extract this ZIP file to a folder on your computer.
3. Open Android Studio -> Click "Open" -> Select the extracted folder.
4. Wait 30 seconds for Gradle to sync automatically.
5. In the top menu bar, click: **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
6. When finished, a notification popup will appear at the bottom right saying "APK(s) generated successfully". Click **"locate"**.
7. You will find `app-debug.apk`. Transfer this file to your phone via USB cable, WhatsApp, Google Drive, or Bluetooth and tap **Install**!

### Option 2: 100% Free Cloud Build with GitHub Actions (No Android Studio required!)
1. Upload this extracted folder to a new GitHub repository (free).
2. Go to the "Actions" tab in your repository.
3. Click "Build WE TOGETHER Android APK" -> Click "Run workflow".
4. GitHub will build the APK in 90 seconds!
5. Download `WE_TOGETHER.apk` directly from the Artifacts section.

### Option 3: Instant 1-Click Android PWA Installation
Open the web app URL in Google Chrome on your Android phone, tap the 3 dots (⋮) menu at the top right, and tap **"Install app"** or **"Add to Home Screen"**. The app will install as a native standalone app with camera, microphone, and notifications!
